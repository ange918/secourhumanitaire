# Fode — landing page

Landing page statique (HTML/CSS/JS, sans dépendance) : hero « Italian Pasta With Special Sauce »,
puis Why Fode?, Menu filtrable, About, How it works, Reviews et CTA.

Lancer : `python3 -m http.server 8000` puis ouvrir http://localhost:8000

Animations : entrée du hero à chaque chargement (le plat arrive de la droite), parallaxe à la souris,
apparition au scroll, compteurs, coupon qui défile.
